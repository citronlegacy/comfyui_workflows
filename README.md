# ComfyUI Workflows

A place to save, share, and maintain my [ComfyUI](https://github.com/comfyanonymous/ComfyUI) workflows.

## Structure

Workflows are grouped by type in folders (e.g. `video/`). Each workflow lives in its own subfolder.

## Usage

1. Download the workflow `.json` file.
2. Drag and drop it onto the ComfyUI canvas (or use **Load**).
3. Install any missing custom nodes or models via ComfyUI Manager.
